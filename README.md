# Devkit

Central de comandos e skills reutilizáveis para os meus projetos. A ideia é
reunir aqui instruções e fluxos de trabalho que uso com frequência, mantendo-os
organizados e fáceis de adaptar ou compartilhar entre repositórios.

## Organização

```text
.
├── commands/   # Comandos e fluxos de trabalho reutilizáveis
└── skills/     # Skills e recursos relacionados
```

## Como usar

Este repositório funciona como catálogo central. Copie ou adapte os comandos e
skills para cada projeto, respeitando a estrutura esperada pela ferramenta
utilizada nele.
